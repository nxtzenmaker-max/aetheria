## 🌌 Overview

**Aetheria** is a cutting-edge web platform combining 3D WebGL visuals, procedural audio, multi-agent AI execution simulations, and cosmic dark glassmorphism into a fluid, responsive experience.

---

## ✨ Features & Architecture

### 1. 🪐 3D WebGL Cosmic Core & Ambient Particle Nebula
- Interactive **Three.js** 3D scene featuring a rotating morphing icosahedron core, inner octahedron, dual gyroscopic orbital rings, and 1,400 glowing starfield particles.
- **Dynamic Mouse Parallax & Click Pulse**: World group rotates and responds in real-time to cursor coordinates, scroll offsets, and mouse clicks.
- **Graceful Zero-Dependency Fallback**: Automatically falls back to an HTML5 Canvas 2D interactive constellation physics engine if WebGL/CDN is unavailable.

### 2. 🧠 Interactive Neural Synthesis Studio
- In-browser code synthesis simulator supporting 4 presets:
  - **Quantum Raymarcher** (GLSL shader with chromatic dispersion)
  - **Swarm Router** (Rust & tokio Byzantine-fault-tolerant consensus mesh)
  - **Spatial HUD** (Three.js gyroscopic parallax matrix)
  - **ZK Proof Circuit** (Circom Groth16 neural attestation)
- Real-time token streaming animation, syntax styling, copy-to-clipboard with toast feedback.
- Interactive **Spatial Resonance Visualizer** canvas rendering dynamic wave harmonics and swarm node matrices.
- Dynamic telemetry chips: Throughput (T/s), P99 Latency (ms), and GPU Load (%).

### 3. 🍱 Interactive 3D Bento Grid & Holographic Cards
- **3D Tilt & Specular Lighting**: Cards dynamically tilt in 3D perspective following the mouse cursor with radial spotlight sheen.
- **Interactive Synthesizer Soundboard**: 8 touch pads (or keyboard keys `1` through `8`) playing warm procedural Web Audio synthesizer tones.
- **Live Planetary Telemetry Widget**: Simulates active edge nodes, ingress bandwidth (Gbps), and consensus block heights.

### 4. 🎨 Adaptive Multi-Theme Engine
- Four hand-crafted futuristic themes:
  - **Cyber Prism (Default)**: Deep obsidian navy with glowing electric cyan & violet accents.
  - **Solar Flare**: Deep onyx with amber gold, ruby glow, and warm embers.
  - **Emerald Matrix**: Dark titanium with mint green and holographic emerald.
  - **Nebula Dream**: Cosmic purple with magenta and celestial pink.
- Synchronized color mapping updating both CSS variables and Three.js 3D materials in real-time.

### 5. ⌨️ Command Palette (`Cmd+K` / `Ctrl+K`)
- Keyboard-accessible search modal for instant navigation, theme changing, audio control, and Easter eggs.
- Full arrow-key selection, Enter to execute, Escape to dismiss.

### 6. 🔊 Zero-Asset Web Audio Synthesizer
- Built entirely on native browser `AudioContext` — zero MP3/WAV assets to load.
- UI hover chirps, click transients, warm pentatonic musical notes, ambient synth drone, and harmonic success chords.
- Persistent mute/unmute state in `localStorage`.

### 7. 💎 Flagship Projects & Case Studies Lightbox
- Interactive category filter (All, Autonomous AI, Spatial 3D, FinTech & Systems).
- Deep-dive case study modal detailing project telemetry, architecture specifications, and technology stacks.

### 8. ✉️ Interactive Commission & Budget Deck
- Real-time project allocation slider ($15,000 to $150,000 USD).
- Form validation with animated feedback.
- Custom zero-dependency **Canvas Confetti Fireworks** burst upon submission with unique mission receipt tokens.

## 🛠️ Technology Stack

- **Markup & Layout**: Semantic HTML5, CSS Grid, Flexbox, Glassmorphism, CSS Custom Properties
- **3D Graphics & Shaders**: Three.js (r128) + Pure HTML5 Canvas 2D Fallback
- **Sound Synthesis**: Native Web Audio API (`AudioContext`, `BiquadFilterNode`, `GainNode`)
- **Typography**: Google Fonts (*Syne*, *Space Grotesk*, *Inter*, *JetBrains Mono*)
- **Performance**: Zero bulky frameworks, 60fps hardware-accelerated animations, fully responsive

## 🚀 Quick Start / Local Preview

Serve the directory with Python:

```bash
cd aetheria
python3 -m http.server 3000
```

Then navigate to `http://localhost:3000` in your browser.
